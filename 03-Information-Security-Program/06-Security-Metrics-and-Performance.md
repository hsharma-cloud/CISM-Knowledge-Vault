# Security Metrics & Performance Measurement

> **Document Version:** 1.0
> **Last Updated:** 2026-10-04
> **Domain:** Information Security Program
> **Topic:** Security Metrics & Performance Measurement

## Definition

Security metrics measure the effectiveness of the information security program and help management determine whether security objectives are being achieved.

## Why It Matters

Good metrics support informed business decisions, justify security investments, and identify areas for improvement.

## CISM Key Points

- Metrics should support business objectives.
- Use KPIs to measure performance.
- Use KRIs to measure risk.
- Report trends, not just numbers.
- Review metrics regularly.

## CISSP Connection

CISSP discusses security metrics. CISM emphasizes using metrics to demonstrate business value and improve the security program.

## Exam Tip

Executives want meaningful metrics that support decisions—not technical statistics without business context.

## Real-World Example

The security manager reports phishing success rates, incident response times, and policy compliance trends to executive management each quarter.
