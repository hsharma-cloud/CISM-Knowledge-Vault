# Domain 3 Summary – Information Security Program

## Goal of Domain 3

Build, operate, measure, and continuously improve an information security program that supports business objectives.

## Topics to Remember

### 1. Information Security Program
- Supports business objectives.
- Implements security strategy.
- Uses a risk-based approach.

### 2. Security Program Governance
- Align with business goals.
- Define accountability.
- Measure performance.

### 3. Security Controls
- Select controls based on risk.
- Balance cost and business value.
- Review effectiveness regularly.

### 4. Security Awareness & Training
- Everyone has security responsibilities.
- Training should be continuous.
- Measure effectiveness.

### 5. Resource Management
- Prioritize high-risk initiatives.
- Allocate people, budget, and technology wisely.
- Balance cost and value.

### 6. Security Metrics
- KPI = Performance
- KRI = Risk
- Report trends and business value.

### 7. Security Program Lifecycle
- Plan
- Implement
- Operate
- Monitor
- Improve

### 8. Continuous Improvement
- Learn from audits.
- Learn from incidents.
- Update the program continuously.

---

# Top CISM Mindset

Ask yourself:

- Does this support business objectives?
- Is this risk-based?
- Does this improve the security program?
- Does this provide value to the organization?

---

# CISSP vs CISM

CISSP asks:

"How do I implement security?"

CISM asks:

"How do I manage an effective security program?"

---

## Domain 3 Quick Review Checklist

✓ Security supports the business.

✓ Resources are limited—prioritize by risk.

✓ Measure performance.

✓ Continuously improve.

✓ Think like a security manager, not an engineer.
