# Program Review & Continuous Improvement

> **Document Version:** 1.0
> **Last Updated:** 2026-10-04
> **Domain:** Information Security Program
> **Topic:** Program Review & Continuous Improvement

## Definition

Program Review and Continuous Improvement ensure the information security program remains effective, aligned with business objectives, and responsive to changing risks.

## Why It Matters

Business, technology, and threats constantly change. Regular reviews help keep the security program relevant and effective.

## CISM Key Points

- Review the security program regularly.
- Evaluate effectiveness using metrics and audits.
- Address findings from incidents and assessments.
- Update policies, controls, and processes.
- Support continual improvement.

## CISSP Connection

CISSP discusses continuous improvement. CISM emphasizes improving the overall security program to deliver ongoing business value.

## Exam Tip

When the exam asks what management should do after an audit, assessment, or incident, the best answer is usually to review the results and improve the security program.

## Real-World Example

Following an internal audit, the organization updates security policies, improves employee training, and enhances monitoring based on identified gaps.
