# CISM Knowledge Vault

A concise study repository designed to bridge the gap between **CISSP** and **CISM**.

## Purpose

This repository is **not** intended to replace the official ISACA CISM Review Manual.

Its purpose is to:

- Summarize key CISM concepts.
- Highlight the CISM management mindset.
- Focus on business, governance, and risk.
- Serve as a quick review before the exam.

## Study Strategy

1. Read the official study materials.
2. Review these notes.
3. Complete practice questions.
4. Update the notes with lessons learned.

---

## Guiding Principles

- Business before technology.
- Governance before implementation.
- Risk-based decision making.
- Security enables the business.
- Think like a security manager.

---

## Goal

Create a concise **CISSP → CISM Bridge** that can be reviewed quickly before the exam while reinforcing the CISM mindset.
